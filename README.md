# Digital-clock
Welcome to the Digital Clock project! This project demonstrates a simple yet functional digital clock created using HTML, CSS, and JavaScript. It displays the current time in a 24-hour format and updates every second. You can also customize the clock's style and appearance as needed.

#Features ✨
Real-time clock: Displays the current time and updates every second.
Responsive design: The clock looks great on both desktop and mobile devices.
Customizable styles: You can change the clock's color, font, size, and background using CSS.
Simple and easy to use: No additional setup is required, just open the index.html file in your browser.

3. Customization
You can customize the following elements:

Clock Format: The clock uses a 24-hour format. You can modify the JavaScript code (script.js) to switch to a 12-hour format if desired.
# Technologies Used ⚙️
HTML: Structure of the digital clock.
CSS: Styling and layout of the clock.
